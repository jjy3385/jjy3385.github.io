# 핀토스? PintOS? Pintos?
Nachos -> Pintos<br>
멕시코 음식에서 유래됐다는 얘기도 있고 Pint OS, 즉 작은 OS란 유래도 있는거 같음
그냥 난 핀토스라고 부르겠음
아무튼 핀토스는 스탠포드대학에서 만든 교육용 OS 프레임워크임
실제 PC의 CPU에 설치하는 형태는 아니고 QEMU라는 소프트웨어 위에서 작동함
QEMU는 에뮬레이터라고 불리는 건데, CPU,메모리,디스크,주변장치같은 하드웨어를 흉내낸 소프트웨어임

내가 공부한 핀토스는 KAIST에서 자기네 운영체제 과목에 맞게 다시 정리한 거임
즉, 카이스트 핀토스이고 CPU도 x86-64 기준으로 구현됨

# 프로젝트 소개
원래 핀토스는 4개의 프로젝트로 구성되어 있음
* 프로젝트1 : 스레드
    * 스레드 스케줄링과 동기화, 즉 운영체제가 어떻게 CPU자원을 각 프로세스에게 잘 나눠주는가에 대해 배움
* 프로젝트2 : 유저 프로그램
    * 유저 프로그램을 위한 인자 전달과 시스템콜, 즉 운영체제가 어떻게 응용 프로그램에게 적절한 인자와 기능을 제공해주는지 배움
* 프로젝트3 : 가상 메모리
    * 물리 메모리를 추상화한 가상 메모리, 즉 운영체제가 어떻게 각 프로세스에게 무한한 메모리를 가졌다고 착각하게 만드는지 배움
* 프로젝트4 : 파일 시스템
    * 디스크 위에 파일과 디렉토리, 즉 운영체제가 어떻게 저장 장치를 관리하는지 배움


# 목표
